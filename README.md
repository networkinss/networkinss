# Hi, I'm Oliver 👋

**Senior Software Engineer  
Full-Stack Developer · Architect · DevOps · AI Development**  
25+ years in software engineering, 15+ years of Java, based in Zürich, Switzerland.

## 🔭 What I work on

### Full-stack development
* **Java / Spring Boot** microservices (Spring Boot 1.x to 4.x), API-first design with OpenAPI.
* **Go** web services with Gin or net/http, CLI tools, and desktop applications with Wails.
* **Python** with FastAPI for lightweight web services; machine learning and model training with PyTorch and pandas.
* **React / TypeScript** and **Angular** frontends; desktop applications with Electron and Wails.
* **Enterprise-grade applications** in banking, insurance, and healthcare: Spring Boot, Azure, relational databases (Oracle, PostgreSQL), and NoSQL (MongoDB, Cosmos DB, Cassandra).
* **Security:** OAuth 2.0, OpenID Connect, JWT, Keycloak, Zitadel, and Microsoft Entra ID (formerly Azure AD).

### DevOps and cloud
- **Kubernetes**, Helm, ArgoCD (GitOps), **Terraform**, Ansible, Docker.
- CI/CD with GitLab, Jenkins, Azure DevOps and GitHub Actions.
- **Azure** (AKS, Functions, Cosmos DB, Key Vault, API Management), **GCP** and **AWS**.
- Monitoring with Prometheus, Grafana, Kibana and Splunk.
- **LPIC-1** certified; Linux/Unix (and Windows) administration for over 10 years. 

### AI development
- **AI platform**, **Spring AI**, LangChain, **RAG on pgvector**, local LLMs with **Ollama**, on-prem LLMs.
- **MCP servers** and AI agents: designing and building agent integrations for enterprise systems.
- **Agentic engineering** in daily practice with Claude Code and GitHub Copilot, from code generation to refactoring and reviews.
- Leading internal **workshops** on AI capabilities and agents.
